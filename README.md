Freelancer Payment System
About the Project

I built this Freelancer Payment System to understand how real freelance platforms manage projects and payments between clients and freelancers.
The main idea of this project is to make sure that payments are handled only after project approval and to avoid confusion between both sides.

This project helped me learn how real-world workflows work in full-stack applications.

What I Have Done:

Created a system where users can register and login as Client or Freelancer

Implemented role-based dashboards for both client and freelancer

Client can create projects and assign them to freelancers

Freelancer can view assigned projects and submit completed work

Client can review the work and approve the project

Payment status is updated only after approval

Implemented secure authentication and session handling

Designed a simple and responsive UI

Roles in the System:
Client:

Create and assign projects

Review freelancer submissions

Approve projects

Track payment status

Freelancer:

View assigned projects

Submit completed work

Track project and payment status

Technologies Used:

Frontend: React, HTML, CSS, JavaScript

Backend: Node.js, Express.js

Database: MongoDB

Authentication: Session-based authentication

Version Control: Git and GitHub

How the System Works:

User registers and logs in as a client or freelancer

Client creates a project and assigns it

Freelancer completes the project and submits it

Client reviews and approves the project

Payment status is updated after approval
